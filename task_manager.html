Basic Workflow (Flow Chart)

  • 1
    Admin: 'Add New Task List' se employee ki profile aur unke daily/weekly tasks banata hai.
  • 2
    Employee: Apps page (launcher) se apne ERP login se 'My Tasks' kholte hain, kaam poora karte hain aur photo proof upload karte hain.
  • 3
    System (Scoring): Time par kaam hone par full points milte hain. Late hone par Score Master ke rules ke hisaab se automatic penalty lagti hai.
  • 4
    Management (MD): 'MD Oversight View' me live report, pending tasks dekhte hain aur actions lete hain.

Buttons ke Features

Add New Task List: Naye employee register karna aur unke tasks set karna.
MD Oversight View: Sabhi employees ka live status dekhna aur action lena.
Employee Score Card: Sabhi ki total performance % ek sath check karna.
Score Master: Late kaam hone par points katne ke rules set karna.
EA Delegation: Special one-time task dena aur postpone karna.
Assign Buddy: Chhutti par jane wale ka kaam kisi dusre ko transfer karna.

Kaun sa button kisko dikhega, ye ERP ke Admin Panel › Tab Visibility › Task Manager › Home Buttons (role-wise) aur Users › Apps (ek user ke liye) se set hota hai. Ab koi alag password ya PIN nahi hai.

Employee Rules & Scoring

Kya Karein (Do's)

  • Apne sabhi tasks time par complete karein.
  • Kaam poora hone par hamesha sahi photo (Proof) upload karein.
  • Leave par jane se pehle manager se apna 'Buddy' assign karwayein.
  • 'My Score' me apni performance check karte rahein.

Kya NA Karein (Don'ts)

  • Galat ya purani photo upload bilkul na karein.
  • Bina reason EA task postpone na karein (extra penalty lagegi).
  • Tasks ko pending na chhodein, late hone par score minus hoga.
  • Apna ERP login PIN kisi ke sath share na karein (har tick aapke naam se save hota hai).

Score calculation kaise hoti hai?

Har task ke 100 points hote hain, agar Target Time tak kaam ho jaye. Target Time ke baad 3 ghante ka Grace Time milta hai: Grace me kaam kiya to 20 points katenge. Grace ke baad har ghante (ya Score Master ke hisaab se har din) 20 points aur katte rahenge, aur der hone par points minus me chale jaate hain (−20, −40 …). Har task card par live dikhta hai ki abhi kitne points milenge aur agla cut kab hoga. Scoring usi din se shuru hoti hai jis din task assign hua ho, aur Score Master ka naya rule sirf naye assign hue tasks par lagta hai (purane score kabhi nahi badalte). Self tasks score me nahi gine jaate.

Score Master Settings

Every task is worth 100 points when done by its target time.

How points work: done by the target time = full points. Done within the grace time after it = the grace deduction once. After the grace time, the late penalty is taken for every hour (or day) started, and keeps going into minus (−20, −40 …) the later it gets. Set Lowest points to stop it at a limit; leave it blank for no limit.
Changes never re-score the past. A new rule applies only to tasks assigned after you save: daily / weekly / monthly / yearly tasks from the next day on, EA and self tasks created after the save. Tasks already on a sheet keep the rule they were assigned under.
